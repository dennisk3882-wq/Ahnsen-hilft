# Ahnsen hilft – Verwaltungs-Dashboard

Das interne Verwaltungs-Dashboard nutzt dasselbe visuelle Designsystem wie die Bürger-PWA.

## Designprinzipien

- Ahnsen-Grün, Creme und natürliche Akzentfarben
- responsive Karten- und Tabellenansichten
- mobile Verwaltungsnavigation
- einheitliche Statusfarben für offene, laufende und erledigte Vorgänge
- gemeinsame Gestaltung für Mängel, Veranstaltungen, DGH, Mülltermine und PWA-Inhalte

Diese Datei dokumentiert den Stand des Dashboard-Redesigns aus Pull Request #51.
